Fascinating Number:

Given a three-digit integer value N, we define N as intriguing if, after a specific adjustment, the resulting number contains all the digits from 1 to 9 in a non-repetitive manner and does not include any instances of 0. The adjustment involves concatenating N with both 2 * N and 3 * N. Print true if N is intriguing; otherwise, print false.

Input Format:
The first and only line of input contains an integer N.

Output Format:
Print true if N is intriguing, or false otherwise.

Constraints
100 ≤ N ≤ 999

Example
Input
327

Output
true

Explanation:
The number obtained by multiplying the N by 2 (654) and then by 3 (981), and then concatenating these results with N, yields 327654981 incorporating all digits from 1 to 9.



import java.util.*;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        int n = sc.nextInt();

        String s = "" + n + (2 * n) + (3 * n);

        boolean[] seen = new boolean[10];
        boolean valid = true;


        for (int i = 0; i < s.length(); i++) {
            int digit = s.charAt(i) - '0';   	//int num = Character.getNumericValue(ch);

            if (digit == 0 || seen[digit]) {
                valid = false;
                break;
            }

            seen[digit] = true;
        }

        System.out.println(valid);
    }
}

import java.util.*;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        int n = sc.nextInt();
        int t = sc.nextInt();

        int cycle = 2 * (n - 1);
        int pos = t % cycle;

        if (pos <= n - 1) {
            System.out.println(pos + 1);
        } else {
            System.out.println(cycle - pos + 1);
        }
    }
}
